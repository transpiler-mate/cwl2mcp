CWL to MCP¶

cwl2mcp converts parsed CWL processes into MCP Tool definitions and writes them as JSON through transpiler-mate-runtime. It does not execute CWL or start an MCP server.

Start here¶

  • Install the plugin and runtime.
  • Generate your first tool definition.
  • Configure output and metadata keys.
  • Use the exported definitions in an MCP server.
  • Look up the CWL-to-MCP crosswalk, Python and plugin API, and generated hint reference.
  • Read about the architecture.

Python 3.10 or newer is required. The runtime discovers the installed plugin via its transpiler_mate.plugins entry point. See the project configuration for dependencies and quality checks.
